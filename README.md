# AI & Data Science Job Salaries 2026 Dashboard

## 🎯 Project Objective

The objective of this project is to analyze AI & Data Science job salary data using Microsoft Excel. The analysis focuses on job roles, salaries, experience levels, education, locations, AI adoption, programming languages, and job-switching trends to generate meaningful business insights.

## 🗂️ Dataset Description

The dataset contains **5,000 AI & Data Science job records**. Each row represents a job record and includes information such as job title, salary, experience level, education level, location, primary programming language, AI adoption, and job switching status.

## 📋 Dataset Columns

| **Column** | **Description** |
| ---------- | --------------- |
| **Job Title** | Title or role of the job |
| **Salary** | Salary associated with the job |
| **Experience Level** | Experience category of the employee |
| **Education Level** | Highest education level of the employee |
| **Location** | Country/location of the job |
| **Primary Language** | Main programming language used |
| **AI Adoption** | Indicates whether AI is adopted in the role |
| **Job Switch** | Indicates whether the employee switched jobs |

## 🔍 Key Insights

**Financial Overview**

- The dataset contains **5,000 AI & Data Science job records**.
- The overall average salary is approximately **98.61K**.
- The total salary value in the dataset is approximately **493.03M**.
- The minimum salary is **12.00K**, while the maximum salary is **372.35K**.

**Job & Experience Distribution**

- Salary varies significantly across different job roles.
- Experience level plays an important role in salary differences.
- The dataset includes Entry, Mid, Senior, Lead, and Executive-level positions.

**Education & Salary Trends**

- Salary patterns vary across different education levels.
- The dashboard compares Bachelor's, Master's, PhD, Bootcamp, and Self-taught candidates.

**Location & Salary Analysis**

- Average salaries differ significantly across countries.
- The dashboard allows users to compare salary trends across different locations.

**AI Adoption Trends**

- AI adoption varies across different job titles.
- The dashboard provides a clear comparison of AI adoption across different roles.

**Programming Language Analysis**

- The dashboard compares average salaries across programming languages such as **Python, SQL, R, Java, Julia, Rust, and Scala**.
- Different programming languages show different salary patterns across AI & Data Science roles.

**Job Switching Trends**

- The dashboard analyzes job-switching behavior among employees.
- This helps provide insights into workforce mobility within the AI & Data Science industry.

## 📌 Conclusion

This project demonstrates how **Microsoft Excel can be used to transform raw job data into meaningful business insights**.

The interactive dashboard makes it easy to analyze salary trends based on **job title, experience level, education, location, AI adoption, programming language, and job-switching behavior**.
